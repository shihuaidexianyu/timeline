# browser-extension

Edge / Chrome 通用的本地扩展骨架。

## 功能

- 监听活动标签页
- 提取当前域名
- 在标签切换、URL 变化、窗口焦点变化和心跳时上报本地服务
- 记住最近一次成功连接的 agent 地址
- 当你打开自托管的本地仪表盘时，自动学习当前 loopback 端口

## 安装

把整个目录作为已解压扩展加载即可。

## 隐私声明

### 权限说明

| 权限 | 用途 |
|---|---|
| `tabs` | 读取活动标签页的 URL 和标题。**代码只读取当前聚焦窗口的活跃标签页**，不遍历或缓存其他标签页。 |
| `windows` | 跟踪哪个浏览器窗口处于焦点状态，只上报聚焦窗口的活动标签页。 |
| `alarms` | 每分钟触发一次心跳，定期上报当前域名。 |
| `storage` | 缓存最近一次成功连接的 agent 地址（`chrome.storage.local`）。 |

### 数据上报

- 扩展**只上报域名**（`hostname`），**不上报完整 URL、路径、查询参数或页面内容**。
- 页面标题是否上报由后端配置 `record_page_titles` 控制，默认开启；可在设置页关闭。
- 扩展只对 `http:` / `https:` 协议的页面生成事件，`chrome://`、`edge://`、`file://` 等内部页面不会上报。
- 所有数据通过 `POST /api/events/browser` 发送到 `127.0.0.1:46215`（或自定义端口），不经过任何外部服务器。

### 为什么需要 `tabs` 权限

Chrome 扩展 API 中，`tabs` 权限允许读取标签页的 `url` 和 `title` 属性。没有这个权限，扩展无法在标签页 URL 变化时获取域名。`activeTab` 权限仅在被用户主动激活时授予（如点击扩展图标），不适合后台静默采集的场景。

如果你对安全性有顾虑，可以审查 `service-worker.js` 中的 `buildPayload` 函数，确认它只提取 `hostname` 并丢弃路径和参数。
